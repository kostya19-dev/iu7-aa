\ssr{ЗАКЛЮЧЕНИЕ}

В ходе выполнения лабораторной работы были реализованны и исследованы алгоритмы рекурсивного и нерекурсивного вывода чисел в диапазоне. Все цели лабораторной работы были достигнуты, а задачи выполнены.
\begin{enumerate}
	\item разработаны и описаны рекурсивный и нерекурсивный алгоритмы решения задачи;
	\item реализованы оба алгоритма;
	\item выполнена оценка трудоёмкости каждого алгоритма;
	\item реализован каждый алгоритм;
	\item проведен анализ объёма памяти, необходимого для выполнения каждой реализации;
	\item проведено сравнение временных затрат реализаций алгоритмов;
\end{enumerate}
