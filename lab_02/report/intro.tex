\ssr{ВВЕДЕНИЕ}

В рамках данной лабораторной работы рассматривается задача вывода всех целых чисел из заданного диапазона $[A, B]$, где $A \leq B$, при условии, что рекурсивная реализация должна обходиться без использования циклов. Для достижения поставленной цели необходимо решить следующие задачи:
\begin{enumerate}
	\item разработать и описать рекурсивный и нерекурсивный алгоритмы решения задачи;
	\item реализовать оба алгоритма;
	\item выполнить оценку трудоёмкости каждого алгоритма;
	\item провести анализ объёма памяти, необходимого для выполнения каждой реализации;
	\item сравнить временные затраты реализаций алгоритмов;
\end{enumerate}
