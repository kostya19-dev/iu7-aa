\ssr{ВВЕДЕНИЕ}

Цель лабораторной работы --- сравнить последовательную и параллельную версии алгоритма проверки связности графа после удаления заданной на вход k-ой вершины.



Для достижения поставленной цели необходимо решить следующие задачи:
\begin{enumerate}
	\item описать последовательный алгоритм проверки связности графа после удаления вершины $k$;
	\item разработать параллельную версию алгоритма;
	\item реализовать оба алгоритма;
	\item выполнить сравнительный анализ зависимостей времени решения задачи проверки связности графа после удаления вершины $k$ от размерности входных данных для реализации последовательной версии алгоритма и для реализации параллельной версии алгоритма, запущенного с единственным рабочим потоком;
	\item выполнить сравнительный анализ зависимости времени работы параллельной версии алгоритма проверки связности графа после удаления вершины, от размерности входных данных при $k$ вспомогательных потоков, $k$ принимает значения: $1, 2, 4, 8, 16, 32, 64$;
\end{enumerate}
