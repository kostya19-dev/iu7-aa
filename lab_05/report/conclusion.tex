\ssr{ЗАКЛЮЧЕНИЕ}

В ходе выполнения лабораторной работы была достигнута поставленная цель: выполнено исследование алгоритмов поиска и проведено их сравнение.

Для достижения цели были решены следующие задачи:
\begin{enumerate}
	\item рассмотрены основные подходы к поиску элемента по ключу в структурах данных и определены условия применимости соответствующих алгоритмов;
	\item выполнена оценка трудоёмкости выбранных алгоритмов (по числу элементарных операций/сравнений) и сформулированы теоретические выводы;
	\item реализованы алгоритмы поиска в виде программы и обеспечена корректность работы на наборе тестов;
	\item проведено исследование: измерено время выполнения, выполнен анализ результатов и проведено сопоставление полученных данных с теоретическими оценками;
	\item сформулированы выводы по результатам сравнения рассмотренных алгоритмов.
\end{enumerate}
