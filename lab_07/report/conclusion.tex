\ssr{ЗАКЛЮЧЕНИЕ}

В ходе выполнения лабораторной работы была достигнута поставленная цель ---
разработка программного обеспечения для автоматизированной проверки
структурных элементов PDF-документов в соответствии с заданным вариантом.

Для достижения цели были решены все поставленные задачи:
\begin{itemize}
    \item разработаны регулярные выражения для проверки корректности
    наименований и расположения структурных элементов документа;
    \item реализована функция извлечения и поиска подстрок в PDF-файлах
    с использованием регулярных выражений;
    \item разработано программное обеспечение, принимающее на вход путь
    к отдельному PDF-файлу либо к каталогу с файлами и выполняющее их
    пакетную обработку;
    \item проведено тестирование программы на наборе PDF-документов,
    приложенных к лабораторной работе;
    \item выполнено сравнение решений, полученных с использованием
    различных больших языковых моделей.
\end{itemize}

Результаты тестирования подтвердили корректность работы разработанного
программного обеспечения и его соответствие требованиям задания.
