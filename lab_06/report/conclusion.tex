\ssr{ЗАКЛЮЧЕНИЕ}

Цель лабораторной работы была достигнута, а именно были выполнены следующие задачи:
\begin{enumerate}
	\item сформулирована постановка рассматриваемого варианта задачи коммивояжёра;
	\item описан и реализован метод полного перебора для поиска гамильтонова цикла с ограничением по длине;
	\item описан и реализован метод решения задачи на основе муравьиного алгоритма без элитных муравьёв и с феромоном, который нельзя обнулить;
	\item выполнена параметризация муравьиного алгоритма по трём его параметрам и оценить влияние параметров на качество получаемых решений относительно эталонного результата;
	\item проведён сравнительный анализ методов по полученному времени выполнения;
	
\end{enumerate}
