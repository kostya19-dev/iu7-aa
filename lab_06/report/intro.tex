\ssr{ВВЕДЕНИЕ}


Целью работы является сравнительный анализ методов решения задачи коммивояжёра на основе полного перебора и муравьиного алгоритма для заданного варианта графа с выполнением параметризации муравьиного алгоритма по его основным параметрам.

Для достижения цели необходимо выполнить следующие задачи:
\begin{enumerate}
	\item сформулировать постановку рассматриваемого варианта задачи коммивояжёра;
	\item описать и реализовать метод полного перебора для поиска гамильтонова цикла с ограничением по длине;
	\item описать и реализовать метод решения задачи на основе муравьиного алгоритма без элитных муравьёв и феромоном, который нельзя обнулить;
	\item выполнить параметризацию муравьиного алгоритма по трём его параметрам и оценить влияние параметров на качество получаемых решений относительно эталонного результата;
	\item провести сравнительный анализ методов по полученному времени выполнения;

\end{enumerate}
